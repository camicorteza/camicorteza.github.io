Caso de estudio: Alke Wallet

Descripción

Evolución de una billetera digital en HTML, CSS y jQuery (con localStorage) a una aplicación con backend propio y base de datos relacional, desarrollada en tres etapas del curso.

Desafío principal

Reemplazar localStorage por una API segura y consistente: autenticación, acceso restringido a los datos de cada usuario e integridad del saldo en cada operación.

Solución propuesta

API REST con rutas privadas protegidas por JWT, un middleware que impide modificar recursos de otros usuarios (401 y 403), operaciones de saldo dentro de transacciones SQL con rollback y subida de archivos validada por tipo y tamaño.

ClienteMiddleware JWTControladorSequelizePostgreSQL
